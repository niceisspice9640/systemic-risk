# The Fragility Gap

An independent research site presenting a study of whether the growth of cyberattacks and infrastructure disruptions has outpaced the defensive and regulatory capacity built to contain them.

## Structure
- `index.html` — landing page (thesis + four-measure overview)
- `v1-incidence.html` — cyberattack incidence (3 Chart.js charts)
- `v2-concentration.html` — cloud concentration (embedded HHI analysis)
- `v3-cascade.html` — cross-sector cascade (embedded heatmap)
- `v4-capacity.html` — institutional response (event study)
- `assets/` — styles, chart configs, and standalone chart pages

## Data
EuRepoC v1.3.2, Synergy Research Group, and a hand-compiled cascade matrix.

## Built with
Plain HTML/CSS/JS + Chart.js 4.4.1. No build step. Hosts directly on GitHub Pages.
